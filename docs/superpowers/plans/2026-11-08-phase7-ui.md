# Phase 7 — UI & Game Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the title screen, in-game HUD, floating text, pause menu, game-over screen, procedural reticle, and the Menu → Arena → Pause/Game Over → Restart/Menu flow with clean restarts.

**Architecture:** `main_menu.tscn` becomes the main scene. Gameplay UI lives inside `arena.tscn` as `CanvasLayer` children. `ArenaController` owns run lifecycle (`_ready`, `restart_run()`, `return_to_menu()`). Restart reloads the arena, which removes every dynamic node (enemies, bullets, particles, scorch marks, tread marks).

**Tech Stack:** Godot 4.7 GDScript, strict static typing, zero external assets.

**Spec:** `docs/superpowers/specs/2026-11-08-phase7-ui-design.md`

## Global Constraints

- Strict static typing on every `var`, parameter, and return type.
- Zero external assets: `Polygon2D` / `Line2D` / `ColorRect` / `Label` / `Button` only.
- Score updates only through `EventBus.score_updated`; do not poll `GameManager.score` per frame.
- Shields react to `EventBus.player_damaged(current_hp, max_hp)`.
- Pause and game-over layers use `process_mode = PROCESS_MODE_ALWAYS`.
- `Esc` uses the existing `pause` input action; redeploy also accepts `ui_accept`.
- `VFXManager.spawn_floating_text()` requires `floating_text.gd` to expose `setup(text: String) -> void`.
- Folder is not a git repo: one task = ledger entry + harness run.
- Temporary harness under `tests/` is deleted before completion.

## Review Focus

1. Deploying always starts a fresh run (score/time/ricochet reset) and the wave timer starts.
2. Restart cleans enemies, bullets, particles, scorch marks, and tread marks by rebuilding the arena, and resets `Engine.time_scale`.
3. Pause overlay stays interactive while `get_tree().paused` is true, and `Esc` does nothing on the game-over screen.
4. Game-over stats are snapshotted when `GAME_OVER` arrives, not recomputed from a live run.
5. Reticle follows the mouse and is hidden outside `PLAYING`; the OS cursor is visible in menu screens.
6. `floating_text.tscn` is preferred over the procedural fallback, and it frees itself.

- instantiate the arena and await one frame;
